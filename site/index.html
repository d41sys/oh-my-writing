Eleven skills

Ask in plain words. You don't need to name a skill.

anti-slop-editing
Cut filler without losing facts.
author-voice
Match a writer’s own samples.
structured-drafting
Turn notes into a draft.
evidence-grounded-writing
Check claims against sources.
independent-review
Get a fresh reader’s critique.
post-writing
Blog posts, essays, newsletters, social posts.
report-writing
Decision memos, executive summaries, post-mortems.
technical-docs
Tutorials, references, READMEs, PR descriptions, changelogs.
career-documents
Truthful résumés, CVs, cover letters, statements.
project-report
Report from project records.
results-visualization
Plot results from data files.

Install

npx github:d41sys/oh-my-writing
  • Claude Code reads ~/.claude/skills.
  • Codex reads ~/.agents/skills.
  • omp reads both.

Needs Node 18+ and git. The repository is private, so your git needs access.
